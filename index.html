Usage

Do / Don't Patterns

How the original site applies each token — distilled into rules for consistent application.

✓ Color: Do

Use gold (#FFBF00) exclusively for brand accents, CTAs, overlines, and active/focus states. It should always stand out.

✕ Color: Don't

Don't use gold for body copy, decorative dividers, or muted-state elements. Overusing it destroys its premium signal.

✓ Typography: Do

Use -0.03em letter-spacing and 1.05 line-height for all display and heading text. This gives the site its tight, editorial feel.

✕ Typography: Don't

Don't use default browser letter-spacing for headings. It produces a loose, generic look that undermines the premium aesthetic.

✓ Cards: Do

Keep cards at --surface background (not --background). The 4% luminance difference between background and card creates subtle, dark-mode-friendly depth.

✕ Cards: Don't

Don't increase border opacity beyond 0.08 for resting states. The border should barely whisper at rest, then become visible on hover via gold tinting.

✓ Glow: Do

Use the gold glow (rgba 255,191,0, 0.22 at 12px blur) on hover states and key CTA buttons. It signals interactivity and reinforces the gold brand.

✕ Glow: Don't

Don't apply gold glow to resting elements or non-interactive content. Constant glow feels synthetic rather than premium.

✓ Spacing: Do

Give sections 80–112px vertical breathing room. The generous whitespace (all in dark) makes the gold moments feel earned.

✕ Spacing: Don't

Don't compress section padding to save space. Tighter spacing on a dark background feels cluttered, not efficient.

  /* Surfaces */

  --card-foreground:     0 0% 100%;
  --surface:             240 6% 8.5%;
  --surface-2:           240 5% 11%;     /* #1B1B1D */
  --secondary:           240 4% 14%;     /* #222225 */
  --secondary-foreground: 240 5% 74%;   /* #B9B9C0 */
  --muted:               240 4% 14%;
  --muted-foreground:    240 5% 74%;
  --popover:             240 6% 8.5%;
  --popover-foreground:  0 0% 100%;

  /* Brand / Gold */
  --primary:             45 100% 50%;    /* #FFBF00 */
  --primary-foreground:  0 0% 7%;        /* #121212 */
  --accent:              45 100% 50%;
  --accent-foreground:   0 0% 7%;
  --gold:                45 100% 50%;
  --gold-soft:           45 100% 50% / 0.12;
